# تطبيق ريموت كنترول أندرويد لشاشة KMC (موديل K18M50262)

تطبيق أندرويد مفتوح المصدر مكتوب بلغة **Kotlin** ويعمل مباشرة عبر منفذ الأشعة تحت الحمراء (`ConsumerIrManager`) بتردد **38kHz** وبروتوكول **NEC / Extended-NEC**.

## بيانات الشاشة المستهدفة
- **الشركة:** KMC
- **الموديل:** `K18M50262` (شاشة 50 بوصة LED Full HD غير ذكية)
- **البانل:** `T500QVN03.5` (إصدار 2018)
- **البروتوكول:** NEC 38kHz (يدعم 7 ملفات أكواد لـ KMC و Changhong و MStar و TP.V56 و CV512H)

## مميزات التطبيق
1. **7 ملفات أكواد جاهزة** تغطي أغلب اللوحات الصينية المستخدمة في شاشات KMC (بما فيها ملف `0x00FF` المشترك مع Changhong/DLC وملفات MStar/TP.V56).
2. **زر الفحص التلقائي (Auto-Scan):** يرسل إشارة التشغيل تلقائياً عبر جميع الملفات كل 1.6 ثانية، وبمجرد استجابة الشاشة اضغط **إيقاف وحفظ الملف**.
3. **مختبر كود HEX يدوي:** لتجربة أي كود NEC من 32 بت (8 خانات Hex) مباشرة.
4. **أزرار كاملة:** التشغيل، المصدر HDMI/AV، الصوت، القنوات، الأسهم، OK، القائمة، الخروج، الأرقام، الوسائط، والأزرار الملونة.

## طريقتان لبناء ملف الـ APK وتثبيته على هاتفك

### الطريقة 1: عبر GitHub Actions (الأسرع بدون تثبيت Android Studio)
1. أنشئ مستودعاً جديداً على حسابك في GitHub وارفع محتويات هذا المجلد إليه.
2. افتح تبويب **Actions** في المستودع، وسيبدأ البناء تلقائياً (ملف `.github/workflows/build-apk.yml` جاهز مسبقاً).
3. بعد دقيقتين، نزّل ملف `KMC-K18M50262-Remote-APK` من قسم **Artifacts** وثبّت `app-debug.apk` على هاتف الأندرويد.

### الطريقة 2: عبر Android Studio على جهازك
1. فك الضغط وافتح المجلد في **Android Studio**.
2. انتظر انتهاء مزامنة Gradle.
3. من القائمة العلوية اختر: `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
4. انقل ملف `app/build/outputs/apk/debug/app-debug.apk` إلى هاتفك وثبّته.
